# Welcome to CVOptimizer

This is a tool for job seekers who want to sharpen their CV and manage their job search more effectively.

All information is stored locally in this browser. To get the most out of CVOptimizer, you need to add an API key — you can do that under **My Account**. Once you have an API key, you can build a skills and experience database by dragging and dropping CVs you have created before. You can then use your skills and experience database to match yourself against job listings with the help of AI.

**Note:** AI can be wrong and all results should be taken with a grain of salt and reviewed with common sense.


## Getting started

Go to **My Account** and add an API key for one of the following AI providers:

| Provider | What you need |
|---|---|
| **OpenAI** (GPT) | API key from [platform.openai.com](https://platform.openai.com) — [How?](https://www.google.com/search?q=youtube+how+to+get+an+api+key+for+openai) |
| **Anthropic** (Claude) | API key from [console.anthropic.com](https://console.anthropic.com) — [How?](https://www.google.com/search?q=youtube+how+to+get+an+api+key+for+anthropic+claude) |
| **Google** (Gemini) | API key from [aistudio.google.com](https://aistudio.google.com) — [How?](https://www.google.com/search?q=youtube+how+to+get+an+api+key+for+google+gemini) |
| **Ollama** (local) | Ollama installed and a model downloaded, e.g. llama3 |

## What can you do?

You can upload one or more CVs. Each CV is analysed and experiences, skills, education and more are extracted into your skills and experience database. You can also manage your database manually.

Your database will grow over time — both by loading more of your CVs and by adding skills mentioned in job listings you come across.

You can paste a job listing and let an AI (the one you have configured) match it against your database, and get suggestions for improvements.

You can search for jobs on Platsbanken (the Swedish Public Employment Service) based on your profile. The results go through a quick surface-level ranking first. For each interesting job you can then run a deeper **AI analysis** to get a more accurate picture of how well you match.

You can generate a CV specifically tailored to the analysed job listing and use it as a starting point when applying for that job.
