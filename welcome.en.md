# Welcome to CVOptimizer

This is a tool for job seekers who want to sharpen their CV and manage their job search more effectively.

All information is stored locally in this browser. To get the most out of CVOptimizer, you need to add an API key — you can do that under **My Account**. Once you have an API key, you can build a skills and experience database by dragging and dropping CVs you have created before. You can then use your database to match yourself against job listings with the help of AI.

Keep in mind that AI can be wrong and that all results should be taken with a grain of salt and reviewed with common sense.

## Getting started

Go to **My Account** and add an API key for one of the following AI providers:

| Provider | What you need |
|---|---|
| **OpenAI** (GPT) | API key from platform.openai.com |
| **Anthropic** (Claude) | API key from console.anthropic.com |
| **Google Gemini** | API key from aistudio.google.com |
| **Ollama** (local) | Ollama installed and a model downloaded, e.g. llama3 |

Then choose a role (Candidate or Salesperson) to access all features.

## What can you do?

**Candidate** – As a candidate you can upload one or more CVs. Each CV is analysed and experiences, skills, education and more are extracted into your skills and experience database, which you can also manage manually.

You can paste a job listing and ask AI to match it against your database, and get suggestions for improvements.

You can generate a CV specifically tailored to the analysed job listing to use as a starting point.

**Salesperson** – As a salesperson you can manage one or more candidates, each with their own skills and experience database based on their CVs.

You can match a job listing against your candidates' CVs to see if the assignment could be a good fit for them.

**Recruiter** – Recruiter features are coming later.
